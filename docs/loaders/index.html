Loading curtain · four motifs

Each panel plays the simulated boot pipeline (script 300 ms · textures 900 · compiled 1600 · ready 2100 · finish 2200) behind a full-screen curtain, then hands off into the fake rail and altimeter over the hero poster. Skip path = world ready in under 250 ms: no motif, fade only. Fullscreen shows real scale; Esc closes.
